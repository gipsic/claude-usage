# Getting help

| I want to… | Go to |
|---|---|
| Report a number that doesn't match the Claude app | [New issue → Wrong number](https://github.com/gipsic/claude-usage/issues/new?template=wrong-number.yml) |
| Report a crash / install problem | [New issue → Bug report](https://github.com/gipsic/claude-usage/issues/new?template=bug.yml) |
| Suggest a feature | [New issue → Feature request](https://github.com/gipsic/claude-usage/issues/new?template=feature.yml) |
| Ask a question, share a setup, show a screenshot | [Discussions](https://github.com/gipsic/claude-usage/discussions) |
| Report a security problem | [Private vulnerability report](https://github.com/gipsic/claude-usage/security/advisories/new) — see SECURITY.md |
| Contribute code | [CONTRIBUTING.md](CONTRIBUTING.md) |

Before filing, `claude-usage doctor` answers most "is it working?" questions and
its output (no secrets) is the first thing we'll ask for.
